# Folder Guide

## Apps/SPIE
Current SPIE app source, icon, PyInstaller spec, and the latest rebuilt executable.

## Spike Processing
Spike-counting, spike-waveform, spike-amplitude, and spike-count plotting scripts.

## LFP Processing
LFP feature extraction, LFP plotting, low-frequency LFP scripts, and spike-LFP coupling code.

## Raw Conversion
Intan RHD/RHS readers, raw-to-CSV conversion scripts, raw chunk combining, and Intan helper packages.

## Plotting and Utilities
Standalone plotting and utility scripts that are not specific to one spike or LFP processing step.

## Demos
Synthetic/demo datasets and scripts.

## Analysis Outputs
Generated validation, smoke-test, and demo output folders.

## tests
Unit tests for the spike, LFP, and spike-LFP workflows.

## Python Environment Folders
`Include`, `Lib`, and `Scripts` are the local Python environment folders and were left at the root so the environment keeps working.
