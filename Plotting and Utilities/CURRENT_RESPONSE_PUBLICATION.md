# Current-response box plots

Current-response figures use the existing preparation means without changing
filtering, normalization, exclusions or scientific tables. Boxes span Q1?Q3,
with medians and 1.5-IQR whiskers. All observations, including outliers, appear
once as uniform 5-point muted-blue circles with thin dark outlines.

The title is ?Post-stimulation firing rate in the locust MTG?. Applied cathodic
current (nA) decreases left to right; firing rate remains percent of baseline
with a dashed reference at 100%. Legends and sample annotations are omitted.

Deterministic collision avoidance moves only overlapping markers horizontally,
by at most 5 nA. Export metadata records actual and displayed coordinates.
Saved legacy legend, marker and offset options remain accepted for compatibility
but do not control this figure. Single/double width selection remains supported.

The existing Plots directory and filename stems are retained. PNG exports use
600 dpi; SVG retains editable text; PDF uses embedded TrueType fonts. All three
formats share dimensions and layout. Other plot types retain their exports.
